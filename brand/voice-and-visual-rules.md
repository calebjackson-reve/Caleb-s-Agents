# Brand rules: Caleb Jackson, Keller Williams First Choice

Compact version of the July 2026 Brand and Content Package (Drive: Caleb-Jackson-Brand-Package.pdf). Every agent in this repo reads this file before producing a public asset. Keller Williams First Choice is the current brokerage. Rêve branding, fonts, colors and language are historical and are not used.

## Visual

| Token | Value | Rule |
|---|---|---|
| Ink | #14100E | All body text on light backgrounds |
| Ivory | #FBF8F3 | Default ground |
| Blush | #FBEFE9 | Secondary ground, sparingly |
| Ember | #E87757 (hover #C95F41) | Once per view. Large display type or graphic elements only. Never body text or small links. |
| Stone | #8D857B | Captions, rules, muted labels |

- Ivory plus ink make up about 95 percent of any view.
- No gradients, no gold, no navy.
- Display type: Instrument Serif, set light and large. Body and UI: Hauora 400, 600, 700. Labels: Hauora SemiBold, uppercase, +0.28em tracking.
- Wordmark: lowercase thin serif "caleb jackson." with an ember period. The j dot is ember. Monogram "aj." for favicon, app and avatar.
- Never add houses, keys, roofs or skylines to the mark.
- "Keller Williams First Choice" appears legibly on site, cards, signs, app and every advertising asset per LREC rules. The personal mark never incorporates the KW logo.

## Slogan treatments (fixed)

| Treatment | Form | Where |
|---|---|---|
| Hero | Action Jackson. | Site hero, video end cards, sign riders |
| Label | ACTION JACKSON | Sub-lockups, social bios, email signature |
| Proof line | One supporting line | Captions, about, listing copy |

Supporting lines, use exactly one at a time:
- When it's time to move, we move.
- Your call gets returned today. Not tomorrow. Today.
- The dream is the easy part.

## Voice

- First person. Short declarative lines.
- Real numbers and place names over adjectives. Receipts over adjectives.
- "Y'all" when earned. Faith on milestone beats, not every line.
- Never "unparalleled service." Never emoji stacks. Never generic AI phrasing.
- No em dashes. No semicolons. Warm, direct, natural.
- Example: "Listed Tuesday. Under contract Friday. That's the job."

## Facts that must be true before publishing

- Every statistic is sourced and dated in the asset or its caption.
- Bracketed bio numbers (years, families, volume, repeat and referral share) are filled with true values or omitted.
- Addresses and client names appear only with permission.
- Fair housing language throughout. No steering by protected class in neighborhood content.
