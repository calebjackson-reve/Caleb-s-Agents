# Caleb-s-Agents

This repository has all the agents and skills I have created in Claude.

## Layout

- `strategy/` dated plans. Start with `strategy/2026-10-07-most-viewed-realtor-plan.md`, the build plan for becoming the most viewed realtor in Baton Rouge. `strategy/site-review-checklist.md` is the pass for the 30-page site preview before it goes into Luxury Presence. `strategy/phase0-google-billing-and-gbp.md` is the action sheet for the Google billing failures and the Business Profile anchor.
- `brand/voice-and-visual-rules.md` the compact brand standard every agent reads first. Keller Williams First Choice is the current brokerage. `brand/profile-copy-kit.md` is the approved paste-ready bio copy for every surface. `brand/profile-update-checklist.md` plus `brand/profile-assets/` are the matching photo and cover set and the per-platform order of work.
- `review-helper/` the Google review form: a guided page that turns a client's answers into a review in their own words and sends them to the Google listing. Request text and email templates are in its README.
- `agents/` one spec per automation: daily brief, lead response, database nurture, review engine, content engine, market receipt, listing launch and the AI visibility baseline.
