# Weekly series scripts

Outline: [`../series-from-research.md`](../series-from-research.md). Script page with rendered frames: https://claude.ai/artifact/WiAWiHZ661WajLewUUgrqX

Each `*-scenes.json` is the script and the scene plan in one file, in the Course 1 motion kit format (branch `claude/course-1-kit`, `programs/ai-for-agents/motion/`). Extra keys `say`, `exact`, `why` and `motion` hold the script and notes, and the kit ignores them. `dur` is an estimate at 176 words a minute. Once Caleb films, swap `dur` for `src` ranges from his take and run `cut_to_scenes.py`.
