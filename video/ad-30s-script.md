# 30-second ad script: Caleb Jackson Real Estate

Format copied from the Nick Saraev / Agent Reach Instagram ad, October 13 2026.
Selling the real estate business, using the site build as the proof.

## The rules of the format

| Element | Spec |
| --- | --- |
| Aspect / length | 9:16, 30 seconds, one visual beat per second |
| Face framing | Rounded card in the lower 40% when a graphic is up; full-bleed for emphasis lines |
| Style A text | Italic serif, ALL CAPS, centered, 1–2 words. Narrative spine. |
| Style B text | Bold sans, sentence case, centered, 1–2 words. Nouns and verbs. |
| Captions | Lowercase, burned in over the chest, continuous, a third smaller style |
| Accent | Coral #E87757 on the single most important word per section |
| Background | Paper #FBF8F3 behind graphics |
| Props | Site clips, never mockups |

Serif is Instrument Serif, sans is Nunito. Both already on the site.

## Captions to burn in

Run continuously, lowercase, over the chest. Each sits about one beat behind the voiceover so it reads as a second voice:

`a link to a listing` · `so I built this` · `shows the work` · `pull it apart yourself` · `understand` · `prepare` · `close` · `same on your phone` · `before it happens` · `no surprises` · `born here` · `text me`

## Shot list for the camera day

One take, 30 to 40 seconds, read the voiceover straight through twice. You only need these framings:

1. **Full-bleed emphasis**, chest up, looking down the lens. Used at 3, 4, 13, 23, 24.
2. **Card framing**, same setup, you sit slightly lower in frame so the top 60% is free for graphics. Used at 8, 15, 16, 27.

Plain wall, window light from the side, mic in frame is fine and matches the reference. Do not move between the two framings; the editor crops.
