# Lessons

- A zero-work queue is meaningful only when its immutable heartbeat is fresh.
- A generator claim cannot grade the generator. Bind trust to independent SQL proof.
- Late in-window evidence supersedes a negative receipt. History stays append-only.
- One event may ground one suggestion. Overlaps are excluded, not counted as failure.
- Outcome calibration is observational, reason-specific, frozen daily, and capped.

## Ignore list

- Duplicate run keys with identical evidence.
- Superseded outcome labels.
- Private message text, names, phone numbers, email addresses, and postal addresses.
- Creator-video patterns already covered by the three-source growth review.
