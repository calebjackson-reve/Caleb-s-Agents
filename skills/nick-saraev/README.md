# Nick Saraev course skills

Every lesson from Nick Saraev's free Maker Zero masterclasses (the same courses he publishes on YouTube), converted into Claude Code skills. Each skill lives in `skills/nick-saraev/<course>/<skill>/SKILL.md` and is linked into `.claude/skills/` so Claude Code loads it automatically when a request matches its description.

## How they load

Claude Code reads the `description` line of every skill under `.claude/skills/` at session start. When what you ask matches a description, that skill's full instructions are pulled into context. You do not have to name a skill. Say the task in plain words ("text every new Zillow lead within a minute", "turn this call recording into a proposal", "audit this app for security") and the right skill loads. To force one, type `/<skill-name>`.

Each course folder also has a `COURSE-NOTES.md` with the thesis, a chapter-by-chapter summary, the skill table and five takeaways for Caleb.

Total: 145 skills across 10 courses.
