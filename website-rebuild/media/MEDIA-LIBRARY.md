# Media library for the website rebuild

Assembled October 19, 2026 from Caleb's Google Drive brand folder (the one holding `Caleb-Jackson-Brand-Package.pdf`, dated July 2026). Everything here is a real photo or a real brand file. Nothing is AI generated. Web-ready copies live in this folder. Originals stay on Drive, links below.

Source rules from the brand package: ink `#14100E`, ivory `#FBF8F3`, blush `#FBEFE9`, ember `#E87757`, stone `#8D8578`. Display type Instrument Serif, body Hauora. Logo never gets houses, keys, roofs or skylines. "Keller Williams First Choice" appears legibly as text.
